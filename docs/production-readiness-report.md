## 2. Immutable Image Tag Migration

As part of this production readiness review, the deployment pipeline was updated to migrate AWS Lambda deployments from generic rolling tags (`:latest`) to **immutable git commit SHA tags**:

- **Build Output**: Pushes both `${REGISTRY}/${REPOSITORY}:${GITHUB_SHA::8}` and `${REGISTRY}/${REPOSITORY}:latest` to Amazon ECR.
- **Terraform Stage 2 Parameter**: Invokes Terraform with `-var="image_uri=${{ env.IMAGE_URI }}"`, forcing AWS Lambda to point directly to the exact container digest generated by the active commit.
- **Benefit**: Guarantees deterministic, reproducible deployments and enables instant 1-click container rollbacks.
